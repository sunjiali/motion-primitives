# Getting help

- **Bugs and feature requests:** GitHub Issues — the templates ask for
  the details that make a motion bug reproducible (composition snippet,
  exact command, frame number).
- **Usage questions:** open an issue with the `question` label and the
  smallest composition that shows what you are trying to do.
- **Security problems:** do not use public issues — see
  [SECURITY.md](SECURITY.md).
- **Before asking:** the README's primitive table and the live site
  (demos + playground) answer most "how do I make it …" questions, and
  `EFFECTS.md` records what is implemented and what is planned.
