Motion primitives
for AI-generated videos.

An LLM is bad at hand-writing animation math — easing curves, spring constants, arc interpolation — but good at composing named building blocks. motion-primitives wraps the motions explainer & teaching videos need again and again into tiny, frame-pure primitives, so the AI writes intent, not math.

const p = M.fly(frame, { at: 60, dur: 90, from, to, arc: 170 });
stage.innerHTML =
  M.dot({ x: p.x, y: p.y, r: 44, color: '#3FB6FF', candy: true });

01 — Why

Why primitives?

01

Frame-pure by design

Every primitive is a pure function of the frame number — same frame, same picture. That is what makes parallel screenshot rendering correct, and live browser previews trivial.

02

Compose, don't calculate

One call per motion: pop() for a springy entrance, fly() for an arc, burst() for confetti. Springs, easings and arcs live inside the library, where they belong.

03

A renderer included

A from-scratch pipeline (headless Chrome screenshots + ffmpeg, in the spirit of Remotion's architecture) turns a plain JS composition into an MP4. No framework, no bundler.

02 — Live demos

05 — Docs

Docs

Quick start

npm install
node src/render.js --comp showcase \
  --out out/showcase.mp4 --concurrency 4
node src/render.js --comp showcase \
  --still 250 --out out/frame.png

Requirements: Node.js ≥ 18, Chrome/Chromium, ffmpeg.

Write a composition

window.Composition = {
  meta: { width: 1280, height: 720,
          fps: 30, durationInFrames: 300 },
  render(frame, stage) {
    const M = window.Motion;
    stage.innerHTML = M.dot({
      x: 640, y: 360, r: 80, color: '#FF8A4C',
      scale: M.pop(frame, { at: 10 }), candy: true });
  },
};

API at a glance

fadeUpFade + rise entrance (style string)
pulseBreathing scale for “look here” targets

staggerStart-frame helper for staggered groups
flyEased arc flight between two points
trailGhost positions trailing a flight
smearMotion blur — exposure ghosts that stretch with velocity and vanish at rest
squashSquash-and-settle after a landing
dotA circle, optional glossy candy look
rippleExpanding ring after an event
burstConfetti / particle burst
badgePill badge that pops in
targetSlotBreathing dashed target ring
scene / transitionScene bookkeeping + edge fades
wiggleDecaying rotational shake (attention / wrong-answer)
typewriterSelf-typing text, optional blinking caret
beat / drop / travelDirected motion: anticipation entrance, gravity fall, fast-start glide
shake / punch / flashThe impact trio: screen shake, camera punch-in, white flash
cameraVirtual camera — keyframed focus + zoom over a still world
meshBgAnimated gradient-mesh background (no more flat voids)
drawOn / barsSelf-drawing strokes and animated bar charts
scrambleText that decodes out of a glyph pool
kenBurns / breathe / fxSlow zoom for stills, idle micro-motion, film grain + vignette
paperElCut-paper shape — flat fill, hard thickness shadow, resting tilt
pivot / stepped / onTwosPaper-puppet joint rotation and stop-motion timing
whipWhip-pan transition — strip offset with a mid-pan blur peak
pathFlyConstant-speed flight along a polyline, with heading angle
flipIn3D flip entrance (rotateX/Y + perspective) with an overshoot settle
counterRollOdometer digit roll that settles in a staggered cascade
drawTextHandwriting-style stroke text that draws itself, then fills in
particleFieldAmbient drifting particle layer — float, snow, and rise modes
morphShapeShape-to-shape morph — circle, square, triangle, diamond, hexagon, star, heart
glitchRGB-split glitch transition — sliced, channel-shifted, envelope-clean edges
beatGrid / beatFramesBPM grid — beat phase and pulse for visuals, frame numbers for SFX scores
morphPolyMorph between two raw polygon point sets — uneven counts subdivided to match
parallaxDepth-layer offsets from one camera move — pairs with camera keys
splitTextSplit-text entrance — per-character stagger in rise, pop, or fade mode
wipeRevealDirectional wipe reveal of any HTML via clip-path — content lands in place
confettiConfetti cannon — seeded paper bits burst, tumble, and fall under gravity
cursorAnimated mouse cursor — keyframed travel, click dip and rings for UI demos
isoBox · isoCylinder · isoWedge · isoPipe · isoSortIsometric solids kit — face-shaded parts on one fixed camera, painted back to front
orbitOrbit pose helper — elliptical squash and depth scaling for satellites and loaders
swingPendulum swing transform — hanging signs and mobiles, with optional decay to rest
marqueeSeamless infinite scroll strip — content repeated and wrapped modulo its unit width

Full signatures and defaults live in src/lib/primitives.ts in the repo — it is heavily commented and doubles as the manual.
