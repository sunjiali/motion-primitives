Every video below was rendered by code — and every one ships with the exact prompt that produced it. Copy a prompt, paste it to your own AI (Claude, ChatGPT, …) together with the motion skill, and it will rebuild the same video for you.

What kind of prompt is this? Not a text-to-video model prompt. These are production instructions for an AI: canvas, timing, scenes, colors, type, and the motion primitives to compose. The AI writes frame-pure code against motion-primitives, the built-in renderer turns it into the MP4 you see. The prompt published here is always the version that actually shipped — iteration notes included.

New entries land with every library release: each motion-primitives iteration adds one prompt + video pair (or revises an existing entry and bumps its iteration notes). Prompts are MIT-licensed with the library — copy, remix, ship.
