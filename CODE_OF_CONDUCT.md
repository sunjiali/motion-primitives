# Code of conduct

This project follows the spirit of the Contributor Covenant: be
welcoming, be respectful of differing experience and viewpoints, give
and accept constructive feedback gracefully, and focus on what is best
for the project and the people trying to use it.

Harassment, personal attacks, and deliberately disruptive behaviour
are not welcome in issues, pull requests, or any other project space.

## Enforcement

If someone behaves badly, a maintainer may edit or remove comments,
close issues or pull requests, and — for repeated or serious cases —
block the account from the project.

To report a conduct problem privately, contact the maintainer through
the contact address on the GitHub profile of @sunjiali, or open an
issue titled "Conduct report — please contact me" **without details**
and a private channel will be arranged.
